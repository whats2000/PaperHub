Mixture-of-Experts with Expert Choice Routing
AI models collapse when trained on recursively generated data

Introduction

Scaling up model capacity, dataset size, and training time has demonstrated huge success in enhancing the performance of computer vision architectures as well as neural language models. The final model quality has been found to have a power-law relationship with the amount of data, model size, and compute time.

Sparsely gated mixture-of-experts (MoE) provides an effective way to scale model capacity given a fixed computational cost. Recent work has implemented sparse routing via -means clustering, linear assignment to maximize token-expert affinities, or hashing. Many of the prior work use a routing strategy concerning the token choice, where each token selects the best one or two experts.

We argue that the independent token choice of prior work often leads to an imbalanced load of experts, which causes training inefficiency and sub-optimal training of the model.
